# CharacterCardDirector（角色卡编排器）

SillyTavern 拓展：按**开场白 Swipe** 自动开合 primary 世界书条目；用**脚本按钮 / QR** 中途切换分组；支持 **MVU 条件绑定**与 **EJS 分阶段**；可在 0 楼插入可 DIY 的**开场白目录页**（8 种布局 + 皮肤编辑器）。配置可写入角色卡，分享 PNG/JSON 后对方可不装本拓展也能用。

**安装**：`https://github.com/Nancyindaeyo/CharacterCardDirector`

---

## v1.1 新功能 · 开场白目录

在 **Swipe #0** 固定插入一个可点击跳转的**目录页**，原有开场白序号整体 **+1**（绑定、命名、封面等配置会自动迁移）。

| 能力 | 说明 |
|------|------|
| **8 种布局模板** | 清单 / 推特 / 微博 / 微信聊天 / Instagram 个人主页 / 手风琴 / 卡组切换 / 日杂风 |
| **样式 DIY** | 模板（布局）× 皮肤（颜色背景）两层架构；5 套预设 + 自定义；面板**实时预览** |
| **逐条定制** | 每条开场白可设**显示名**、**简介**；IG / 卡组模板支持**封面 URL** |
| **目录文案** | 作者简介（类似 IG bio）、操作提示及显示位置 |
| **字体** | 黑体 / 衬线 / 等宽 / 圆体；可粘贴 `@import` 自定义字体（如汇文明朝体）并保存到下拉 |
| **模板装饰图** | 各模板顶栏 / 横幅 / 背景等可填图床 URL |
| **运行时** | 目录页**不触发**世界书开合；停留在目录时**拦截生成**并提示先选开场白 |
| **返回目录** | 进入具体开场白后，0 楼编辑区旁出现「返回目录」按钮 |
| **自愈** | 手动删掉目录 swipe 或聊天丢失时，拓展 / 独立脚本会自动恢复 |
| **导出** | 写入角色卡后由独立脚本接管，无需安装本拓展 |

详细配置见下文 **[5. 开场白目录](#5-开场白目录)**。

## 安装

### 前提

请先安装 [酒馆助手 (JS-Slash-Runner)](https://github.com/n0vi028/JS-Slash-Runner)，版本 **4.8.19+**。

### 扩展管理器安装（推荐）

1. SillyTavern → **扩展** → **Install Extension**
2. 粘贴：`https://github.com/Nancyindaeyo/CharacterCardDirector`
3. 刷新页面 → 左下角魔术棒启用 **角色卡编排器**

## 重要：配置怎么保存

**不会自动写回角色卡。** 编辑只存在本地拓展变量里，必须手动点：

| 按钮 | 作用 |
|------|------|
| **导出到角色卡** | 写入 `character.extensions` + 生成/覆盖独立脚本 |
| **保存配置**（Swipe Tab） | 同上，并同步当前 Swipe 勾选 |
| **同步分组到脚本/QR**（抓取 Tab） | 写入角色卡并更新分组按钮 |
| **保存规则**（条件 Tab） | 保存该条条件（全角色卡范围会写角色卡） |
| **保存到世界书条目**（阶段 Tab） | 将阶段阈值 / EJS / overview 写回世界书 |
| **保存到 initvar / 最新楼层**（阶段 Tab） | 编辑变量数值 |
| **从角色卡加载** | 用角色卡里的配置**覆盖**本地（丢弃未导出的本地修改） |

启用 / 移除目录、修改目录样式或模板时，会自动同步目录正文到角色卡与当前聊天。

分享角色卡 PNG/JSON 前，请先 **导出到角色卡** 或 **同步分组**。

对方不装本拓展时：角色卡上会有独立脚本「世界书前缀按钮」（Swipe + 分组按钮 + 目录运行时）；若有全角色卡条件，还有「世界书条件绑定」（需 MVU）。

## 功能说明

### 1. Swipe 绑定（开场白 ↔ 世界书）

切换 0 楼开场白 Swipe 时，自动按该 Swipe 的配置开合世界书条目。

> **启用开场白目录后**：Swipe **#0 固定为目录页**，不参与世界书绑定；你的第一条实际开场白从 **#1** 开始，面板编号与 Swipe 索引一致。

**怎么配：**

1. 打开面板 → **Swipe 绑定**
2. 展开某个 Swipe → 勾选「切到这个开场白时要开启」的条目
   - 可跨前缀混选（例如现代_ 勾 2 条 + 古代_ 勾 1 条）
   - 可同前缀只勾一部分
3. 可用上方「勾选前缀…」批量勾选某一前缀下全部条目
4. 点 **预览条目** 看「目标开启 / 将开启 / 将关闭」
5. 点 **保存配置** 写入角色卡

**每条开场白卡片还可编辑：**

| 字段 | 说明 |
|------|------|
| **显示名** | 目录页与各模板中展示的标题（留空则用默认） |
| **简介** | 目录列表中的摘要文字 |

**一键开/关：**

- 先勾选若干条目，再点 **一键开/关**
- 当前为「开」的会关掉，为「关」的会打开，立刻写入世界书
- 勾选会清空（只改世界书开合，不等同于保存 Swipe 绑定）

**其它操作（每张 Swipe 卡片）：**

| 操作 | 说明 |
|------|------|
| 跳转 | 切到该 Swipe，并按绑定开合世界书（目录页跳转时不改世界书） |
| 预览条目 / 确认应用 | 预览差量后手动应用 |
| 复制 / 删除 / Branch | 管理开场白文本与分支 |
| 开场白 ↔ 最新楼 | 把 Swipe 文本插入最新楼，或把最新楼写入开场白 |
| 调整顺序 | 移动 Swipe 索引（绑定会跟着重排；目录 swipe 钉在 #0） |

**从旧脚本迁移：**
若角色卡上还有旧版「基于前缀 / `SWIPE_PREFIX_RULES`」脚本，面板可 **从旧脚本迁移**。迁移后请关掉旧脚本，避免双重开合。

### 2. 抓取 / 分组（QR / 脚本按钮）

把世界书条目分成若干**组**，组名 = 脚本按钮名 / QR 名，点击后按策略开合对应条目。

#### 2.1 抓取模式

| 模式 | 匹配方式 | 列表示例 |
|------|----------|----------|
| **前缀匹配** | 条目名以该字符串开头 | `现代_, 古代_, 西幻_` → `现代_人设` 归入 `现代_` |
| **提取关键词** | 条目名**任意位置**包含该词 | 关键词 `人设` → `xxx人设xxxx` / `人设xxxx` / `xxxxx_人设` 都归入「人设」 |

- 列表用逗号分隔；按长度优先匹配（更长的优先）
- **从条目名推导 / 拆词**：从前缀或 `_` 分段自动生成候选，再自行删减
- 右侧 **实时扫描** 显示每组命中哪些条目、未匹配有哪些

#### 2.2 自定义分组

1. **添加分组** → 填写组名（= 按钮/QR 名）
2. **勾选条目** → 手动指定本组包含哪些 UID
3. 自定义组优先于前缀/提取匹配

编辑过程只存本地；配完后点 **同步分组到脚本/QR**。

#### 2.3 QR / 按钮开合策略

默认：点一个组 → **关掉其它组**（全部互斥），再点同一组可关闭。

可自定义：

| 设置 | 含义 |
|------|------|
| **常态开启** | 勾选的组在点其它组时**不会被关掉**（仍可再点自己关掉） |
| **互斥集合** | 每行一组、组内逗号分隔。只在**同一行**内互斥；不同行互不影响 |

示例：

```text
现代_, 古代_
人设, 文风
```

- 点「现代_」只关「古代_」，不影响「人设」「文风」
- 点「人设」只关「文风」
- 若某组勾了「常态开启」，点互斥同伴时也不会关它

互斥集合留空 = 仍使用「全部非常态组互斥」的旧行为。

改完后务必 **同步分组到脚本/QR**。

#### 2.4 按钮出现在哪

同步/导出后，角色卡脚本会注册按钮（酒馆助手 `replaceScriptButtons`），一般出现在脚本按钮栏 / QR 旁。
也可在 QR 里调用（若环境已暴露）：

```javascript
wbSqTogglePrefix('现代_')
```

选开局阶段是否禁用前缀切换，可在面板相关选项中控制（默认偏安全：未开局时禁用）。

### 3. 条件绑定（MVU）

当 MVU 变量满足条件时，额外开启/关闭指定世界书条目。

**怎么配：**

1. **条件绑定** Tab → **重新扫描** MVU 字段（Zod 脚本 / 当前 `stat_data`）
2. **添加条件** → 选作用范围：
   - **全角色卡**：写入角色配置，导出后对方可用独立脚本（需 MVU）
   - **仅该聊天**：只存在当前聊天变量，**不进**独立脚本
3. 可视化规则：选变量、比较符、值（支持 AND / OR）
   - 比较符含：**存在**、**介于**（填 `20,50`）、**包含**；值以 `@另一字段` 开头可字段间比较
4. 勾选条目动作：**满足时开启** / **满足时关闭**
5. **触发时机**：持续生效 / 刚达到时 / 刚离开时；可配边沿动作（toast / flag / inject）
6. **优先级**：多规则命中同一 UID 时，数字大者生效；冲突会在列表上方标红
7. 可选：限定仅在某个 Swipe 索引生效（或全部 Swipe）
8. 点 **保存规则**

手写表达式可用：`getStat` / `getStatOld` / `delta` / `hasKey('路径')` / `len('路径')` / `stageOf('entry-uid')`。

变量路径与 JSON Patch 一致：`/人名/好感度` → 字段 `人名.好感度`。
运行时会监听 MVU `VARIABLE_UPDATE_ENDED`，变量更新后自动重算。

**分阶段宿主条目**（单条目 EJS 分阶段正文）**不会**被条件绑定开关；面板会自动跳过并在底部提示。

每条规则卡片有 **实时诊断**：当前变量值、✓/✗、边沿触发是否会应用条目动作。

### 4. 阶段 / 变量（EJS 分阶段 · 模式 A 伴生）

对接写卡常见的 **单条目 EJS 分阶段**（`getvar('stat_data.xxx')` + `if/else if`）。**不改宿主条目开关**，只做扫描、填值试阶段、编辑阈值并写回世界书。

**怎么配：**

1. 打开 **阶段 / 变量** Tab → **重新加载** / **扫描世界书阶段**（仅扫描**已开启**条目）
2. 在条目卡片中 **填值** 或 **选阶段**，看当前命中哪一档
3. 点击阶段行 **展开**：
   - 有 `stage_names_overview` 的条目：可编辑 **overview 行**（`- 阶段名 (范围)`）
   - 无 overview 的条目：只显示阶段名 + min/max + EJS 条件
   - 修改后 **保存到世界书条目**（overview / EJS 同步写入）
4. 区间有误时标红，并给出小字修复建议（overview 与 EJS 不一致、阶段间空隙/重叠等）
5. **全部变量** 区可编辑 initvar（开场白）或最新楼层 `stat_data` JSON

**新增 EJS 分阶段条目：**

1. 点 **新增 EJS 阶段**（默认隐藏，点击后才展开向导）
2. 勾选一个或多个 **数值变量**
3. 添加若干阶段（阶段名 + 阈值范围 + 行为指导，每行一条）
4. **保存到世界书** → 创建 **蓝灯 🔵**（constant）已启用条目，正文为精简 EJS 链（无 overview、无预设描述，行为指导留空则写入占位）

EJS 宿主条目的正文切换 **不需要** 开关该条目；本 Tab 负责诊断、试值、改阈值与创作新条目。

### 5. 开场白目录

在 0 楼 Swipe 列表最前面插入一页**可点击跳转的目录**，让玩家先选开局再进入具体开场白。

#### 5.1 启用与基本流程

1. 打开 **Swipe 绑定** Tab → **开场白目录** 卡片
2. 点 **添加目录 Swipe**
   - 角色卡 `first_messages` 头部插入目录正文
   - 原有开场白及绑定配置索引整体 **+1**
   - 新聊天默认第一屏即为目录
3. 可修改 **目录标题**（如「选择你的开局」）
4. 配完后 **导出到角色卡**，对方无需安装拓展即可使用

点 **移除目录 Swipe** 会撤销插入并重映射索引（绑定 / 命名 / 封面一并回退）。

#### 5.2 布局模板（8 种）

| 模板 | 风格 |
|------|------|
| **清单** | 编号列表，通用简洁 |
| **推特** | 推文流 · 头像 + 互动栏 |
| **微博** | 动态卡片 · 转评赞 |
| **微信聊天** | 左右气泡 · 对话感 |
| **Instagram** | 个人主页 · 顶栏 bio · **三列正方形网格** |
| **手风琴** | 折叠展开 · 「进入此开场白」在简介下方 |
| **卡组切换** | 左右切换 · 可配封面大图 |
| **日杂风** | 编辑排版 · 竖排文字 · 可调列表字色 |

切换模板会**重建目录正文**（布局结构变化）；仅改皮肤则无需重建。

#### 5.3 样式 DIY

点 **样式 DIY** 展开编辑器（`<details>` 分组，可折叠）：

| 分组 | 可调整项 |
|------|----------|
| **背景** | 跟随酒馆 / 纯色 / 渐变 / 图片 URL + 遮罩 + 模糊 |
| **颜色** | 强调色、文字色（自动或手动）；对比度不足时会警告 |
| **表面** | 玻璃拟态、底色浓度、特效（酸性 / 扫描线） |
| **头像** | 角色头像 / 自定义 URL / 隐藏；圆形或圆角方 |
| **字体** | 预设字体族；自定义 `@import` + 保存到下拉（如汇文明朝体） |
| **目录文案** | 作者简介、操作提示、提示显示位置 |
| **社交模板** | 昵称、@handle、认证徽章、微博来源、微信问候等（随模板显示） |
| **模板装饰图** | 各模板顶栏 / 横幅 / 背景等图床 URL |

**预设皮肤**：跟随酒馆、极光渐变、夜航玻璃、暖纸编辑、酸性荧光。微调后标记为「自定义」。

编辑器右侧为**实时预览**，所见即目录页最终效果。

#### 5.4 条目封面与命名

- 在每条 Swipe 卡片填写 **显示名**、**简介**（目录各模板共用）
- 当模板为 **Instagram** 或 **卡组切换** 时，额外出现 **条目封面 URL** 区块：
  - 每条实际开场白 Swipe 一行 URL
  - 留空则不显示图片
  - IG 格子底部有渐变蒙版 + 标题 / 简介文字

目录列表在 iframe 内**动态读取**当前 swipes 与命名，增删改名后**无需重新生成**目录 HTML。

#### 5.5 运行时行为

| 场景 | 行为 |
|------|------|
| 停留在目录（Swipe #0） | **不触发** Swipe 绑定 / 前缀规则 |
| 在目录页点发送 | **拦截生成**，toast「请先选择一个开场白」 |
| 进入具体开场白（Swipe ≥ 1） | 正常触发世界书绑定 |
| 已选开场白 | 0 楼编辑区旁显示 **返回目录** 按钮 |
| 删掉目录 swipe | 拓展 / 独立脚本**自动恢复**（角色卡或聊天丢失均自愈） |
| 未开启楼层渲染 | 代码块外附纯文本提示，可手动滑动选择 |

#### 5.6 注意事项

- 换**布局模板**需重建正文；换**皮肤 / 文案 / 装饰图**只写 extensions，较轻量
- 外链字体 / 图片请用**图床**；跨域资源可能被浏览器拦截（非致命）
- 目录 swipe（#0）在面板中标记为「目录」，不可与普通开场白混淆操作

### 6. 导出与独立运行（可不装拓展）

点 **导出到角色卡** 或 **同步分组** 后，角色卡会包含：

| 内容 | 说明 |
|------|------|
| `character.extensions.worldbook_swipe_qr_switch` | 完整配置（Swipe / 分组 / QR 策略 / 条件 / 目录样式等） |
| 脚本「世界书前缀按钮」 | Swipe 开合 + 分组按钮 + **目录运行时**（返回键 / 拦截生成 / 自愈） |
| 脚本「世界书条件绑定」 | 仅「全角色卡」条件（需酒馆助手 + MVU） |

若本机已装本拓展，检测到独立脚本在跑时会让路，避免双重开合 / 双重 toast。

## 条目命名建议

- **前缀模式**：`前缀_其余`，如 `现代_人设`、`古代_文风`
- **提取模式**：名称里包含关键词即可，如任意位置的「人设」
- 避免纯数字当组名（会被过滤，常与 Swipe 索引混淆）
