# CharacterCardDirector（角色卡编排器）

SillyTavern 拓展：按**开场白 Swipe** 自动开合 primary 世界书；用**前缀栏 / QR / 脚本按钮**中途切换分组；支持 **MVU 条件绑定**、**EJS 分阶段**与 **initvar / stat_data 试玩**；可在 0 楼插入可 DIY 的**开场白目录页**（8 模板 + 皮肤 + 自由布局 + 分块字体）。配置可写入角色卡，分享 PNG/JSON 后对方**可不装本拓展**也能用（需酒馆助手）。

**安装**：`https://github.com/Nancyindaeyo/CharacterCardDirector`

---

## 发帖简介

1. **开场白绑世界书**：切哪个开局，就自动开/关对应世界书条目；也可预览差量再手动应用。  
2. **前缀栏 / QR 分组**：按前缀或自定义组一键切换玩法（现代 / 古代 / 人设等），支持互斥与常态开启。  
3. **开场白目录页**：Swipe #0 做可选开局目录（清单 / 社交 / IG / 日杂等 8 种模板），样式可 DIY；导出后收卡方不装拓展也能用。  
4. **MVU 条件 + 分阶段**：变量达标自动开关条目；扫描 EJS 分阶段、试玩阈值、改 initvar / 精修变量结构。  
5. **随卡带走**：点「导出到角色卡」写入配置与独立脚本，分享 PNG/JSON 即可。

## 安装

### 前提

请先安装 [酒馆助手 (JS-Slash-Runner)](https://github.com/n0vi028/JS-Slash-Runner)，版本 **4.8.19+**。

### 扩展管理器安装（推荐）

1. SillyTavern → **扩展** → **Install Extension**
2. 粘贴：`https://github.com/Nancyindaeyo/CharacterCardDirector`
3. 刷新页面 → 左下角魔术棒启用 **角色卡编排器**

## 重要：配置怎么保存

**不会自动写回角色卡。** 编辑默认只在本地拓展变量里，需手动：

| 按钮 | 作用 |
|------|------|
| **导出到角色卡** | 写入 `character.extensions` + 生成/覆盖独立脚本 |
| **保存配置**（Swipe） | 同上，并同步当前 Swipe 勾选 |
| **同步分组到脚本/QR**（抓取） | 写入角色卡并更新分组按钮 |
| **保存规则**（条件） | 保存条件（全角色卡范围会进角色卡） |
| **保存到世界书条目**（阶段） | 写回分阶段 overview / EJS |
| **保存到 initvar / 最新楼层**（阶段） | 改变量数值 |
| **从角色卡加载** | 用角色卡配置**覆盖**本地（丢弃未导出修改） |

启用 / 移除目录、修改目录样式或模板时，会自动同步目录正文到角色卡与当前聊天。

分享 PNG/JSON 前请先 **导出到角色卡** 或 **同步分组**。

收卡方不装本拓展时：卡上会有独立脚本「世界书前缀按钮」（Swipe + 分组 + 目录运行时）；有全角色卡条件时还有「世界书条件绑定」（需 MVU）；全局世界书分组另有「世界书全局前缀按钮」。

## 功能说明

### 1. Swipe 绑定（开场白 ↔ 世界书）

切换 0 楼开场白时，按该 Swipe 配置自动开合 primary 世界书条目（**仅开局阶段**）。

> **启用开场白目录后**：Swipe **#0 固定为目录**，不参与世界书绑定；第一条实际开场白从 **#1** 起。

**怎么配：**

1. **Swipe 绑定** Tab → 展开某个 Swipe  
2. 勾选「切到这个开场白时要开启」的条目（可跨前缀混选，也可同前缀只勾一部分）  
3. 可用「勾选前缀…」批量勾选  
4. **预览条目** 看「目标开启 / 将开启 / 将关闭」  
5. **保存本 Swipe**（本地）→ 顶部 **导出到角色卡** 随卡带走  

**每条卡片还可：**

| 操作 | 说明 |
|------|------|
| 显示名 / 简介 | 目录页标题与摘要 |
| 跳转 | 切到该 Swipe 并应用绑定（目录页不改世界书） |
| 一键开/关 | 立刻改世界书开合（≠ 保存绑定） |
| 复制 / 删除 / Branch | 管理开场白（目录 #0 不可删） |
| 开场白 ↔ 最新楼 | 插入最新楼，或把最新楼写入开场白 |
| 调整顺序 | 移动索引（绑定/命名/封面随 remap；目录钉在 #0） |

**从旧脚本迁移：** 若卡上还有旧版 `SWIPE_PREFIX_RULES` 脚本，可用 **从旧脚本迁移**；迁完请关掉旧脚本，避免双重开合。

---

### 2. 抓取 / 分组（前缀栏 · QR · 脚本按钮）

把世界书条目分成若干**组**，组名 = 前缀栏 chip / 脚本按钮 / QR 名。

#### 2.1 作用范围

| 子 Tab | 说明 |
|--------|------|
| **角色 Primary** | 当前角色卡 primary 世界书 |
| **全局世界书** | 多本全局书合并配置，导出为「世界书全局前缀按钮」 |

#### 2.2 抓取模式

| 模式 | 匹配 |
|------|------|
| **前缀匹配** | 条目名以该串开头，如 `现代_` → `现代_人设` |
| **提取关键词** | 名称任意位置包含关键词 |

- 列表逗号分隔；更长串优先匹配  
- **从条目名推导 / 拆词** 生成候选  
- **实时扫描**：命中、未匹配、重复警告  

#### 2.3 自定义分组

手动命名 + 勾选 UID；自定义组优先于前缀/提取匹配。配完点 **同步分组到脚本/QR**。

#### 2.4 QR / 按钮策略

| 设置 | 含义 |
|------|------|
| **常态开启** | 点其它组时不会被关掉（仍可再点自己关） |
| **互斥集合** | 每行一组、行内互斥；不同行互不影响 |

互斥集合留空 = 全部非常态组互斥（旧行为）。

#### 2.5 前缀栏

导出/同步后，输入框上方出现横向 **chips**，游玩中途可切换分组。选开局阶段默认禁用前缀切换（偏安全）。也可在 QR 中调用（若已暴露）：

```javascript
wbSqTogglePrefix('现代_')
```

### 3. 条件绑定（MVU）

变量满足条件时，额外开启/关闭世界书条目。

1. **重新扫描** MVU 字段（Zod 脚本 / `stat_data`）  
2. **添加条件** → 范围：**全角色卡**（进独立脚本）或 **仅该聊天**  
3. 可视化规则：变量、比较符、值（AND / OR）  
   - 比较符含：存在、介于（`20,50`）、包含；值以 `@另一字段` 可做字段间比较  
4. 勾选：**满足时开启** / **满足时关闭**  
5. **触发时机**：持续 / 刚达到 / 刚离开；可配边沿动作（toast / flag / inject）  
6. **优先级**：同 UID 冲突时数字大者生效，列表上方标红  
7. 可选：限定仅某 Swipe 索引生效  
8. **保存规则**；支持从角色卡条件脚本导入  

手写表达式可用：`getStat` / `getStatOld` / `delta` / `hasKey` / `len` / `stageOf`。  
路径与 JSON Patch 一致：`/人名/好感度` → `人名.好感度`。  
监听 `VARIABLE_UPDATE_ENDED`，并有轮询兜底。

**EJS 分阶段宿主条目**不会被条件绑定开关；面板会跳过并提示。  
每条规则有**实时诊断**：当前值、✓/✗、边沿是否会应用。

---

### 4. 阶段 / 变量（EJS · initvar · MVU 精修）

#### 4.1 变量数据源

| 芯片 | 说明 |
|------|------|
| **开场白** | 读/写当前开场白 `<initvar>` YAML |
| **最新楼层** | 读/写最新楼 MVU `stat_data` |

旧式变量格式可 **识别并转换为 initvar**。

#### 4.2 全部变量

列出数字 / 文本 / 布尔字段，改完保存到 initvar 或最新楼 JSON——适合试好感、试阈值，**不必**导出角色卡。

#### 4.3 EJS 分阶段

对接单条目 `getvar('stat_data.xxx')` + `if/else` 分阶段正文（**不改宿主开关**）：

1. **扫描世界书阶段**（仅已开启条目）  
2. 填值 / 选阶段，看命中哪一档  
3. 展开编辑 overview / 阈值 / EJS，**保存到世界书**  
4. 区间错误会标红并提示  
5. **模式 B**：勾选多阶段拆成独立条目 + 条件（OR）  
6. **新增 EJS 阶段**：选数值变量 → 配阶段 → 创建蓝灯条目  

#### 4.4 MVU 变量精修（四步向导）

| 步骤 | 内容 |
|------|------|
| **① 结构** | 可视化编辑 zod 变量树 |
| **② 初值** | 编辑 initvar YAML |
| **③ 更新规则** | 编辑变量更新规则 YAML |
| **④ 写回** | 勾选写回变量列表 / zod 脚本等 |

可从角色脚本 `registerMvuSchema`、开场白 initvar、世界书「变量更新」等导入；草稿可存拓展本地。

### 5. 开场白目录

在 0 楼最前插入可点击跳转的**目录页**，玩家先选开局再进入正文。

#### 5.1 启用

1. **Swipe 绑定** → **开场白目录** → **添加目录 Swipe**  
2. `first_messages` 头部插入目录；原开场白与绑定索引整体 **+1**  
3. 可改**目录标题**；配完 **导出到角色卡**  

**移除目录**会撤销插入并重映射索引。

**切卡行为：** 换角色卡时目录样式会回默认（**字体偏好永久保留**），并按当前卡重读开场白列表，避免串卡残留名称/简介。

#### 5.2 八种布局模板

| 模板 | 风格 |
|------|------|
| 清单 | 编号列表 |
| 推特 / 微博 / 微信 | 社交流 / 气泡 |
| Instagram | 主页 + 三列网格 |
| 手风琴 | 折叠展开 |
| 卡组切换 | 左右翻页 + 封面 |
| 日杂风 | 竖排 + 可调列表字色 |

换模板会重建目录正文；只改皮肤/文案通常只写 extensions。

#### 5.3 样式 DIY（已落地）

点 **样式 DIY**（分组可折叠）+ 右侧**实时预览**：

| 分组 | 能力 |
|------|------|
| **背景** | 跟随酒馆 / 纯色 / 渐变 / 图片（遮罩、模糊、裁剪） |
| **颜色与表面** | 强调色、文字色、玻璃、透明度；特效：酸性 / 扫描线 / 噪点 / 暗角 / 网格 / 发光 |
| **头像** | **角色（char）** / **用户（user）** / 自定义 URL / 隐藏；圆形或圆角方 |
| **字体** | 黑体 / 衬线 / 等宽 / 圆体；粘贴 `@import` 可保存到下拉（如汇文明朝体）；跨卡保留 |
| **目录文案** | bio、操作提示与位置 |
| **社交 / 日杂** | 昵称、@handle、徽章、问候、期号、竖排字等 |
| **模板装饰图** | 顶栏 / 横幅 / 背景等图床 URL |
| **预设皮肤** | 跟随酒馆、极光、夜航玻璃、暖纸、酸性荧光 |

**布局编辑：** 预览内拖拽 / 缩放元素；左侧调 z 序与隐藏；**保存样式**才写入；可恢复默认流式布局。

**额外装饰图：** 多 URL 批量粘贴（`---` / `|` / 换行）→ 独立摆放；支持裁剪蒙版。

**文字排版：** 点选区域改字号 / 字重 / 斜体 / 对齐 / **独立字体**；预览可选简繁展示（不改存储原文）。

**条目封面：** IG / 卡组模板下可为每条开场白填封面 URL。

#### 5.4 运行时

| 场景 | 行为 |
|------|------|
| 停在目录 #0 | **不触发**世界书绑定 |
| 目录页点发送 | **拦截生成**，提示先选开场白 |
| 进入开场白 ≥ 1 | 正常应用 Swipe 绑定 |
| 已离开目录 | 0 楼 mes 栏出现 **列表图标**，一键回目录 |
| 目录被删 | 拓展 / 独立脚本**自愈**恢复 |

#### 5.5 不装拓展也能用吗？

**可以**——作者先 **导出到角色卡**，收卡方启用 **酒馆助手** 上的「世界书前缀按钮」即可（含返回目录、拦截生成、自愈）。本机同时开着拓展时，拓展会让路给独立脚本，避免双重逻辑。
